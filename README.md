# Customer Behavior Analysis

## Overview

Customer Behavior Analysis is a data analytics project focused on understanding customer purchasing patterns, preferences, and behavior using data analysis and visualization techniques.

The project follows an end-to-end data analytics workflow, starting with data loading and cleaning in Python, performing Exploratory Data Analysis (EDA), analyzing data using SQL in PostgreSQL, and presenting key insights through an interactive Power BI dashboard.

The goal is to transform raw customer data into meaningful insights that can support better business decisions.

## Dataset

The project uses a customer behavior dataset containing information about customer demographics, purchasing activities, product preferences, and transaction details.

The dataset is loaded into Python for preprocessing and analysis before being used for SQL queries and dashboard development.

## Tools & Technologies

- **Python:** Data loading, cleaning, and analysis.
- **Pandas:** Data manipulation and preprocessing.
- **NumPy:** Numerical operations.
- **PostgreSQL:** Database management and SQL analysis.
- **Power BI:** Interactive dashboard creation.
- **Jupyter Notebook:** Performing and documenting data analysis.

- Imported the dataset into Python using Pandas.

### 2. Exploratory Data Analysis (EDA)

### 3. Data Cleaning
- Checked for missing and duplicate values.
- Handled inconsistent data and incorrect data types.
- Cleaned and prepared the dataset for further analysis.

### 4. SQL Analysis (PostgreSQL)
- Imported the cleaned dataset into PostgreSQL.

- Used filtering, aggregation, grouping, and joins where required.
- Extracted meaningful business insights from the data.

### 5. Power BI Dashboard
- Connected the analyzed dataset to Power BI.
- Created interactive charts, graphs, and KPI cards.
- Designed a dashboard to highlight important customer behavior metrics.
- Used filters and slicers for interactive data exploration.

## How to Run

Follow these steps to explore the project locally.

### Prerequisites

Make sure you have installed:

- Python 3.x
- Jupyter Notebook
- PostgreSQL
- Power BI Desktop

### 1. Clone the Repository

```bash
[git clone https://github.com/Taniya-Pal123/customer_behavior_analysis.git](https://github.com/Taniya-Pal123/customer_behavior_analysis.git)
```

### 2. Navigate to the Project Directory

```bash
cd /d C:\Sales_Analysis_Project
```

### 3. Install Required Python Libraries

```bash
pip install pandas numpy  sqlalchemy psycopg2-binary jupyter
```

### 4. Run the Jupyter Notebook

```bash
jupyter notebook
```

Open the notebook and execute the cells to perform data loading, cleaning, and exploratory data analysis.

### 5. Run SQL Queries

- Create a database in PostgreSQL.
- Import the cleaned dataset.
- Execute the SQL queries provided in the project SQL folder.

### 6. Open the Power BI Dashboard

Open the `.pbix` file using Power BI Desktop to explore the interactive dashboard.
